# 桌面／手機版型調整報告

日期：2026-10-16（Asia/Taipei）。依使用者提供的桌面 Chrome 截圖調整，7／7 項任務完成，沒有執行瀏覽器檢測或部署。

## 已實作

- 1024px 起使用固定側邊導覽、緊湊等級／streak 設定列，移除桌面的底部導覽與大橫幅。主內容可用到約 1200px，單字／文法／複習另限制閱讀寬度。
- 1280px 起首頁為主側欄：今日任務與複習在主欄，目前等級掌握與進階建議在側欄。較小桌面先保留主欄寬度，輔助資訊用兩欄；手機依 DOM 順序堆疊，任務不再被五級進度推到下面。
- 手機保留單欄、五分頁底部導覽、安全區、可換行選項／按鈕及觸控尺寸。導覽改為共用 SVG 線條圖示，延用明朝體、indigo／paper 與淺色。
- 今日任務整理為安排控制、三個步驟與個別完成量；保留 loading／error／empty／missing／ready、重試與失效修復。安排中停用重複操作，全部已安排時不提供無效的重複建立。
- 全部等級進度、備份、備考路線用原生 details／summary 展開。原備份驗證／匯出／恢復流程保留；儲存錯誤時自動展開備份，練習頁亦提供回首頁匯出入口。
- 寬螢幕讀解原文／備註與問題並排，聽力題目使用兩欄；較窄裝置回單欄。
- 所有尺寸共用一個 RouterView、TodayTasks、Pinia store 與練習頁；不依 JS viewport 重複掛載，沒有變更題庫、學習規則、v5 資料或持久化所有權。

## 2026-10-16 間距跟進

依使用者第二張錯題複習截圖修正：題型控制改為具 16px gap、下方 24px 留白的工具列；label 與 select 以 8px 間距排列。頂列、主內容與頁尾共用外層 gutter，784px 閱讀寬度移到內層，避免錯題頁另行置中而錯位。較矮桌面側欄縮減裝飾與留白，避免選單內容高度迫使品牌區被捲出畫面。移除舊 span 的強制白色，讓桌面 streak 文字正確繼承桌面色彩。

`npm run check` 再次通過（78 個測試），`npm run build` 與差異空白檢查通過。此處為截圖及原始碼定位後的局部樣式修正；沒有新增僅鏡射 CSS 的測試，也未執行瀏覽器像素或真實焦點驗證。
