## ADDED Requirements

### Requirement: 桌面與手機必須有不同的導覽與內容配置

系統 MUST 在 1024px 以上提供桌面側邊導覽與較寬內容區，並隱藏手機底部導覽；較窄裝置 MUST 保留五個底部主分頁與安全區。響應式切換 MUST 共用同一個 RouterView 與學習狀態，不得依寬度重複掛載練習頁。

#### Scenario: 桌面開啟首頁
- **WHEN** viewport 寬度為 1440px
- **THEN** 版面 MUST 使用側邊導覽與分欄首頁
- **AND** 今日任務 MUST 在五級總覽之前呈現

#### Scenario: 手機練習
- **WHEN** viewport 寬度為 390px
- **THEN** 內容 MUST 採單欄、底部五分頁及觸控尺寸控制
- **AND** 導覽 MUST 保留手機安全區與內容底部空間

#### Scenario: 練習中調整寬度
- **WHEN** 使用者調整視窗寬度
- **THEN** 系統 MUST 只調整版面，不重新掛載題目或清除當輪答案

### Requirement: 首頁必須優先提供學習入口

首頁 MUST 將今日任務與複習置於主要內容，再提供目前等級進度與進階建議。完整五級總覽、備份表單與備考路線 MUST 仍可由具語意的展開控制操作；未知題數、載入失敗、零題與失效目標 MUST 保留可辨識狀態與重試／修復。

#### Scenario: 今日尚未建立
- **WHEN** 使用者開啟首頁且尚無當日計畫
- **THEN** 首頁 MUST 顯示建立今日任務與預期的三組練習
- **AND** MUST NOT 要求先捲過五級完整進度

#### Scenario: 任務目標不可確認
- **WHEN** 題庫失敗或目標失效
- **THEN** 對應任務 MUST 顯示重試或明確修復入口
- **AND** MUST NOT 顯示為完成

#### Scenario: 操作進度備份
- **WHEN** 使用者展開備份區塊
- **THEN** 原匯出／匯入／恢復表單 MUST 可用且保留原先驗證與錯誤訊息

### Requirement: 練習工作區必須適應內容與裝置

桌面讀解 SHOULD 將文章上下文與問題並排，聽力 SHOULD 使用多欄題目配置；較窄裝置 MUST 回到單欄。題幹、選項、按鈕及進度碼 MUST 能換行或適應可用寬度，不改單次提交、解析、語音停止及持久進度契約。

#### Scenario: 開啟讀解文章
- **WHEN** 使用者開啟一篇文章
- **THEN** 原文、備註及問題 MUST 同時存在於單一學習實例
- **AND** CSS MUST 依寬度切換並排或堆疊
