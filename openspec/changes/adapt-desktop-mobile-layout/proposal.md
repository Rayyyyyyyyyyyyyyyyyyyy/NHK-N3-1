## Why

使用者提供桌面截圖，指出目前 520px 手機單欄、巨大橫幅及固定底部導覽在桌面造成大量空白；五級進度先出現，今日任務要長距離捲動才看得到。需要依裝置寬度採不同資訊配置，而非只把手機畫面置中。

## What Changes

- 1024px 以上採桌面側邊導覽、緊湊設定列與較寬工作區；手機保留底部五分頁和單欄，平板採過渡寬度。
- 首頁以今日任務／複習為主、目前等級進度與進階建議為輔；五級進度、進度備份及備考路線可展開。
- 今日任務整理為清楚的安排控制、三個步驟與個別狀態／開始入口；降低常態畫面的維護操作干擾。
- 練習頁保留適當閱讀寬度；桌面讀解原文／問題並排，聽力使用題目網格，手機恢復單欄。

## Capabilities

### New Capabilities

- `responsive-learning-layout`: 桌面與行動導覽、首頁優先序與練習工作區。

### Modified Capabilities

無；這是 add-daily-learning-and-review 完成後的 UI 跟進，不改其學習、狀態或儲存規則。

## Impact

影響 App、HomePage、TodayTasks、讀解／聽力頁與共用 CSS；使用現有 Vue、Pinia、hash 路由、色彩與明朝體。沒有新依賴、資料格式、題庫、外部設定或部署變更。測試使用 happy-dom／型別／建置；依使用者規範不啟動或操作瀏覽器，無真實視覺驗收聲明。
