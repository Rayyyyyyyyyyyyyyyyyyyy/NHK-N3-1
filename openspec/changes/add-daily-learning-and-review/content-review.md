## 自動結構檢查

`npm run check:data` 與負例測試涵蓋四類必要欄位／非空文字、有效等級、唯一 ID、文章至少一題、四個不同選項及 counts。新增文章都有標題、類型、內文、詞彙備註，新增聽力都有完整逐字稿。這些檢查可以找出重複答案、空文章、重複子題 ID 與過期 counts，不能證明日語自然度或官方等級對應。
